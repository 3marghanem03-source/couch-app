# coach_sessions

Coach–client session booking MVP (**Flutter + Supabase**).

- **Supabase:** run `supabase/migrations/001_initial_schema.sql`, then set `SUPABASE_URL` and `SUPABASE_ANON_KEY` in `assets/app.env` (see `assets/app.env.example` and [supabase/README.md](supabase/README.md)).
